Logo PNG exporter

Renders the B3 mark to a 1024 × 1024 PNG and downloads it. Use that file as the input for flutter_launcher_icons.

splitwise_logo.png

1024 × 1024 · sRGB · iOS-ready (no rounded corners — iOS applies the mask automatically).

After downloading, drop splitwise_logo.png into assets/icon/ in the project root and run:
dart run flutter_launcher_icons

That regenerates every iOS icon size under ios/Runner/Assets.xcassets/AppIcon.appiconset/ from this single PNG.
